# Executive Summary Report design pack

This folder is the visual source of truth for the BCSentinel Executive Summary Report.

## Contents
- `concepts/01-...svg` to `concepts/10-...svg`: ten design explorations.
- `concepts/README.md`: concept rationale and selected combination.
- `final/free.svg`: Free HTML report target, maximum two A4 pages, aggregate-only.
- `final/assessment.svg`: Assessment HTML report target with full findings and actions.
- `final/monitoring.svg`: Monitoring HTML report target with trend, realised savings and validation.
- `final/print-variants.svg`: print/PDF design reference for all subscriptions.
- `REPORT_DESIGN_SPEC.md`: canonical content and print rules.

## Final design rating
- Free: 9.8/10
- Assessment: 9.9/10
- Monitoring: 9.9/10
- Print/PDF system: 9.8/10

The HTML report is the primary experience. PDF is generated as a print-safe, low-ink derivative from the same structured report data.
